OpenTransLive

An open-source tool for live transcription and translation.

Self-host captions for talks and livestreams. Share multilingual subtitles on venue screens, phones, or alongside YouTube.

For Event Organizers

One caption stream, many viewers.

Speakers and captioning teams produce a shared stream for conferences, public hearings, and livestreamed talks. Viewers follow in their preferred language without an account. Deploy the framework on your own infrastructure and configure the transcription and translation providers you want to use. Hosting and external AI services may have their own costs.

Key Features

One-to-many broadcast

A speaker or captioning team feeds the session; viewers follow captions in their browser without logging in.

Multi-language, multi-engine

Use ElevenLabs Scribe or Gemini for browser microphone transcription, or connect external clients. Translate into multiple languages with configurable AI providers.

Stage screens & YouTube subtitles

Project captions on the venue screen, share a QR code for phone viewing, or overlay live subtitles on a YouTube stream.

Roles & Permissions

Permissions separate public viewing, session operation, and server administration. They are not subscription plans.

Audience
No login required. Watch public live captions, choose a display language, and adjust the viewing layout on the live or YouTube viewer page. Viewing does not grant session control or access to an owned session's transcript exports.
Session Owner
Sign in with email OTP to establish session ownership. Manage languages, keywords and settings in the panel, edit saved captions, and export JSON or SRT. Only the primary owner can manage the session's co-owners.
Co-owner
Sign in with an email authorized by the primary owner. Help operate that session's panel, adjust settings, edit captions, and export transcripts. Collaboration access is specific to the sessions shared with you.
System Administrator
Manage accounts, grant or revoke realtime transcription access, set per-account language limits, and review usage. Administrators can also access owned sessions for management. This role is configured by the server operator.

Realtime transcription is a separate permission. Using the panel's microphone or streaming audio to the server requires the operating account to have realtime access granted by this instance's administrator. Owning a session or being a co-owner does not enable it automatically. System administrators have realtime access by default.

Anonymous sessions have no protected ownership. A session without an owner can be operated without login, and anyone can claim its panel control after the 30-second heartbeat expires. Sign in before creating a session to protect ownership. Audience pages remain public even when the session has an owner.

For account access on this instance, contact its server administrator.

Start a Session

Enter a Session ID to open its control panel on this server.

Sign in first to establish protected ownership for a new session. For an existing owned session, use the owner's or an authorized co-owner's account. Viewers should use the audience link shared by the organizer.

Valid format: letters, numbers, hyphens (-), and underscores (_) only. Length: 4-64 characters.
