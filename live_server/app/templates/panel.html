Languages

Select target translation languages. Add a custom BCP-47 code (e.g. ja-JP) if it's not in the list.

Keywords

Keywords help the transcriber recognize names, jargon, or phrases. Pin a keyword to keep it from being auto-removed, or use to look its translations up on the web and add them to the glossary.

Dictionary

Glossary

Keeps names and jargon translating the same way every time. One entry holds one term written in several languages; the wanted spelling is swapped in before translating.

Replace

Replace specific phrases. Choose Flow to fix the source transcript, or a language to rewrite that translation's output.
